Versi final:
JavaScriptexport function summarizeOrders(orders, taxRate = 0.11) {
  if (!Array.isArray(orders)) throw new TypeError('orders must be an array');

  const valid = orders.filter((order) => order.status === 'paid');
  const subtotal = valid.reduce((sum, order) => sum + order.qty * order.unitPrice, 0);
  const discount = valid.reduce((sum, order) => sum + (order.discount || 0), 0);
  const taxable = subtotal - discount;
  const tax = Math.round(taxable * taxRate);

  return {
    count: valid.length,
    subtotal,
    discount,
    tax,
    total: taxable + tax,
  };
}
Penjelasan setiap bug


Assignment di dalam filter()
JavaScriptorder.status = 'paid'
Ini bukan perbandingan, tetapi assignment. Akibatnya semua order diubah menjadi paid dan semuanya lolos filter.
Harus:
JavaScriptorder.status === 'paid'
Ini juga memperbaiki efek samping tersembunyi: fungsi sebelumnya memodifikasi array input.


count menghitung semua order
JavaScriptcount: orders.length
Expected hanya menghitung order berstatus paid, jadi harus:
JavaScriptcount: valid.length


Diskon justru ditambahkan ke nilai kena pajak

JavaScriptconst taxable = subtotal - discount;


total juga menambahkan diskon

Total yang benar adalah nilai setelah diskon ditambah pajak:
JavaScripttotal: taxable + tax
