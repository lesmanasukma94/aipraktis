Yang benar-benar dapat dibuktikan hari ini

1. Aplikasi ChatGPT biasa

Free bukan lagi sekadar “demo”. OpenAI secara eksplisit menyebut unlimited everyday text chats dengan GPT-5.6 Luna, dengan abuse guardrails. Namun upload, image generation, voice, deep research, memory/context dan beberapa tool lain mempunyai akses terbatas. Plus memperbesar akses tersebut dan memberikan advanced reasoning GPT-5.6. 
ChatGPT
+1

Ada satu perbedaan model yang cukup tegas: Free tidak mendapat GPT-5.6 Sol untuk Chat biasa, sedangkan Plus mendapat advanced reasoning dengan GPT-5.6. Namun berapa tepat jumlah reasoning prompt Plus per jam/hari/minggu tidak dibuktikan oleh halaman pricing umum.

2. ChatGPT Work dan Codex bukan Chat biasa

Ini penting karena sering tercampur. Work adalah pengalaman agentic untuk riset, analisis, dokumen, spreadsheet, presentasi, report, dan pekerjaan multistep; Codex khusus engineering/coding. 
OpenAI Help Center

Untuk akses permukaan:

Free: Work terbatas pada desktop; Codex terbatas.

Plus: Work diperluas ke desktop, web, dan mobile; Codex mendapat expanded usage. 
ChatGPT

Untuk Codex Plus, OpenAI memang menerbitkan rentang penggunaan per 5 jam, tetapi jumlah aktual sangat dipengaruhi model dan pekerjaan. Karena OpenAI tidak menerbitkan angka Free ekuivalen pada tabel tersebut, klaim seperti “Plus mendapatkan 5× Codex dibanding Free” tidak memiliki bukti cukup dari sumber resmi yang diperiksa. 
ChatGPT

3. API benar-benar terpisah

Ini yang paling tegas: ChatGPT Plus ≠ langganan OpenAI API. Plus tidak memberikan kuota/token API. Penggunaan API memiliki billing sendiri berdasarkan model/token dan fitur API yang digunakan. 
OpenAI Help Center
+1

Jadi ketika membandingkan Free vs Plus, jangan memasukkan “akses API” sebagai keuntungan Plus. Bukti resmi justru mengatakan sebaliknya.
