Cara membaca bukti ini
1. Aplikasi ChatGPT — Free vs Plus
Bukti paling aman saat ini adalah:


Free: GPT-5.6 Luna, dengan akses ke web search, analisis data, file/gambar, GPTs, image generation, dan fitur lain, tetapi tool memiliki limit tersendiri. OpenAI Help Center+1


Plus: mendapatkan akses model/reasoning yang lebih tinggi, termasuk GPT-5.6 Sol Medium dan High, serta rate limit lebih tinggi dibanding Free. OpenAI Help Center+1


Voice: ada perbedaan limit yang cukup spesifik dan terdokumentasi. OpenAI Help Center


2. ChatGPT Work dan Codex
Jangan menyamakan keduanya dengan "model ChatGPT biasa".
OpenAI secara eksplisit memisahkan Work dan Codex dari pengalaman ChatGPT standar. Untuk GPT-5.6, misalnya, Work memiliki Sol/Terra/Luna pada Plus, sedangkan Codex memiliki Terra pada Free dan Sol/Terra/Luna pada Plus. OpenAI Help Center
Selain itu, Work/Codex mempunyai konsep agentic usage/credits yang berbeda dari sekadar jumlah pesan ChatGPT. OpenAI Help Center
3. OpenAI API
API bukan benefit yang otomatis diberikan oleh langganan ChatGPT Plus. Sumber GPT-5.6 memperlakukannya sebagai produk terpisah dan menyatakan Sol, Terra, dan Luna tersedia melalui OpenAI API. OpenAI Help Center
Jadi, klaim seperti "Plus memberi sekian token API per bulan" tidak didukung oleh sumber-sumber di atas. Bukti tidak cukup / klaim tersebut jangan dibuat. Demikian pula, limit API harus diperiksa pada dokumentasi/pricing API tersendiri, bukan tabel perbandingan ChatGPT Free/Plus.
